# 🌀 OMEGA MULTIVERSE

A sci-fi RPG made with **Python and Pygame**.

Explore huge procedural dimensions, fight unique aliens and bosses, unlock powerful characters, use special abilities, complete quests, collect rare loot, craft upgrades, play minigames and uncover the secrets of the Omega Core.

## ✨ Features

* 🌍 Large procedural and explorable dimensions
* ♾️ Expanding world maps
* 👽 Unique aliens and signature creatures
* 👑 Different boss for every dimension
* 🗺️ Unique environments for every world
* 🌲 Trees, crystals, strange creatures and biome decorations
* 🎭 Unlockable playable characters
* ⚡ Unique abilities for every character
* 🔫 Advanced Portal Gun with multiple modes
* 🌀 Portal combos and special abilities
* 💥 Ultimate abilities and VFX
* 💎 Rare, Epic and Legendary loot
* 🧩 Crafting system
* 📜 Quests and progression
* 🎒 Inventory and equipment
* 📈 XP, levels and skill tree
* 🏆 Achievements
* ☢️ Corruption system
* 🌌 Random dimensional events
* 🛋️ Chill Room with multiple minigames
* 💾 Save system
* 🖥️ Fullscreen support

## 🖥️ System Requirements

* **OS:** Windows 10/11 (64-bit)
* **CPU:** 2-core processor, ~2 GHz or better
* **RAM:** 4 GB
* **GPU:** Integrated graphics or better
* **VRAM:** 512 MB+
* **Storage:** 500 MB free space
* **Python:** 3.10+
* **Pygame:** 2.x

### Recommended

* **OS:** Windows 10/11 (64-bit)
* **CPU:** 4-core processor or better

* **GPU:** Intel UHD / AMD Vega / NVIDIA or equivalent

* **Python:** 3.11–3.13
* **Pygame:** 2.x

## 🚀 Installation

Install Python first.

Then install the required package:

```bash
pip install -r requirements.txt
```

Start the game:

```bash
python main.py
```

## 🎮 Controls

### Movement & Combat

* **WASD** — Move
* **LMB** — Shoot
* **SPACE** — Dash
* **R** — Change Portal Gun mode
* **V** — Ultimate
* **Z / X** — Character abilities
* **J** — Time Rewind

### Menus

* **C** — Characters
* **I** — Inventory
* **K** — Skill Tree
* **Q** — Quests
* **L** — Statistics
* **B** — Armory
* **O** — Crafting
* **T** — Chill Room
* **N** — Nexus
* **TAB** — Portal Lab
* **E** — Portal / Dimension interaction
* **M** — Dimension Map

### Other

* **SHIFT + P** — Portal
* **Y** — Change Portal Combo
* **G** — Use Portal Combo
* **F11** — Toggle Fullscreen
* **ESC** — Close menus

## 💾 Save System

The game automatically saves your progress.

Your save file is:

```text
omega_save.json
```

This file stores things such as:

* Level
* Credits
* Characters
* Weapons
* Upgrades
* Skills
* Quests
* Dimensions
* Boss progress
* Crafting materials
* Achievements
* Chill Room progress
