# 🌀 OMEGA MULTIVERSE

A sci-fi RPG made with Python and Pygame.

## Features

* 🌀 Multiple dimensions
* 👽 Unique alien enemies
* 👑 Boss fights
* 🔫 Portal Gun
* 🎭 Playable characters
* ⚡ Unique character abilities
* 📜 Quests
* 🎒 Inventory and progression
* 🛋️ Chill Room and minigames
* 💾 Save system

## Installation

Install Python and run:

```bash
pip install -r requirements.txt
```

Then start the game:

```bash
python main.py
```

## Controls

* WASD — Move
* LMB — Shoot
* SPACE — Dash
* C — Characters
* Z / X / V — Abilities
* T — Chill Room
* B — Armory
* TAB — Portal Lab
## System Requirements

### Minimum

* **OS:** Windows 10/11 (64-bit)
* **CPU:** 2-core processor, ~2 GHz or better
* **RAM:** 4 GB
* **GPU:** Integrated graphics or better
* **VRAM:** 512 MB+
* **Storage:** 500 MB free space
* **Python:** 3.10+
* **Pygame:** 2.x

### Recommended

* **OS:** Windows 10/11 (64-bit)
* **CPU:** 4-core processor or better
* **RAM:** 8 GB+
* **GPU:** Intel UHD / AMD Vega / NVIDIA or equivalent
* **Storage:** 1 GB free space
* **Python:** 3.11–3.13
* **Pygame:** 2.x
