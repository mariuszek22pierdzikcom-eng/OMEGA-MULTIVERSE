# 🌀 OMEGA MULTIVERSE

A sci-fi RPG made with Python and Pygame.

## Features

* 🌀 Multiple dimensions
* 👽 Unique alien enemies
* 👑 Boss fights
* 🔫 Portal Gun
* 🎭 Playable characters
* ⚡ Unique character abilities
* 📜 Quests
* 🎒 Inventory and progression
* 🛋️ Chill Room and minigames
* 💾 Save system

## Installation

Install Python and run:

```bash
pip install -r requirements.txt
```

Then start the game:

```bash
python main.py
```

## Controls

* WASD — Move
* LMB — Shoot
* SPACE — Dash
* C — Characters
* Z / X / V — Abilities
* T — Chill Room
* B — Armory
* TAB — Portal Lab
